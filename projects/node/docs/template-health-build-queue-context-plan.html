Template Health Build Queue Context

Repo: blockdag-corechain Branch: feature/corechain-template-health-build-queue-context Base: feature/corechain-nodeworker-template-health-context Risk: low

This task adds advisory source-level visibility into whether a template rebuild is already queued when mining health is inspected.

Problem

getTemplateHealth reports the last template build, but not whether a new build is currently pending. Operators still have to guess whether a stale-looking template is actively being worked through.

Goal

Expose pending_template_build, reason, and priority, plus last build age, as advisory fields for dashboards, watchdogs, and nodeworker logs.

Boundary

Do not consume the queue, change template scheduling, change mining policy, or make pending queue state restart-eligible.

Definition Of Done

  • Design committed before code.
  • Health RPC includes pending build context when a request is queued.
  • Nodeworker can decode and print this advisory context.
  • Tests prove pending build state does not change MineableNow, SubmitReady, or restart eligibility.
