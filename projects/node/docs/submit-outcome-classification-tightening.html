Submit Outcome Classification Tightening

Structured submit outcomes become operational truth for the pool. This branch narrows one broad classifier so a generic sync message containing not current is not reported as the more specific p2p_not_current unless the message is actually about P2P state.

The intent is cleaner dashboards and router evidence, not a consensus or mining behavior change. P2P-specific messages still return p2p_not_current; generic node/chain currentness remains node_syncing.
