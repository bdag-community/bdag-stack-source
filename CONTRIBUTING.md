# Contributing to BDAG Community releases

This repository publishes the BDAG Community stack and its corresponding source. Submit software changes to the [component repository](https://github.com/orgs/bdag-community/repositories) that owns the code, using its `develop` branch.

For a change to this repository's release documentation, fork it and open a pull request to `develop`. Explain what needs correcting and link the relevant public release or component revision. Preserve release provenance and applicable licence notices. Released assets and tags refer to specific builds and their checksums.

Francois (`@franco-is`) and Jeremy (`@strattice`) review and merge changes. They promote reviewed `develop` changes through a separate pull request to `main`.

For a security issue, follow [SECURITY.md](SECURITY.md).
